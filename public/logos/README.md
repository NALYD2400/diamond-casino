# Logos des cartes de collection

Déposez ici le logo de chaque marque en **PNG transparent** (carré ou large, ~512 px).
La carte l'affiche automatiquement ; sans fichier, elle garde son logo typographique.
Une URL saisie dans la console (Collections → Cartes → Logo) est prioritaire.
